# Verhaltenskodex

Wir wollen eine respektvolle, einladende Zusammenarbeit. Erwartet wird: sachliche Kritik, Respekt vor anderen Meinungen und Hintergründen, Verantwortung für eigene Fehler.

Nicht akzeptabel sind Beleidigungen, Belästigung, Diskriminierung, das Veröffentlichen privater Daten anderer sowie Aufrufe zu Rechtsverstößen (z. B. Zugriff auf fremde Geräte).

Verstöße melden Sie vertraulich an die Maintainer über GitHub (Private Vulnerability Reporting oder Direktnachricht). Maintainer können Beiträge entfernen, Beteiligte verwarnen oder ausschließen. Dieser Kodex lehnt sich am Contributor Covenant 2.1 an.
