# Sicherheitsrichtlinie

## Meldung von Schwachstellen

Bitte Sicherheitslücken **nicht** öffentlich als Issue melden, sondern über GitHub "Report a vulnerability" im Repository (Private Vulnerability Reporting). Sie erhalten eine Antwort in der Regel innerhalb von 7 Tagen.

## Projektgrenzen

- Keine Veröffentlichung oder Extraktion von App-Schlüsseln, Tokens oder Zugangsdaten Dritter.
- Keine Werkzeuge zum Umgehen von Schutzmaßnahmen oder zum Zugriff auf fremde Konten und Geräte.
- Beiträge, Logs und Mitschnitte müssen von Seriennummern, MAC-Adressen, Tokens und Konto-Daten bereinigt sein.
- Messungen nur an eigenen Geräten und Netzen.
